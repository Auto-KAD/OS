Linux Kernel

Linux uses a monolithic kernel architecture with support for dynamically loadable kernel modules. Major operating-system services such as process management, memory management, file systems and device drivers operate within kernel space.

Microkernel

A microkernel keeps the core kernel functionality small and places many operating-system services in user space. Communication between components commonly uses Inter-Process Communication (IPC).

Project Objective

This project demonstrates the structural differences between monolithic and microkernel designs and allows users to simulate system calls, IPC and component failures.
